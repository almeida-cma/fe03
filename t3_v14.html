🧱 1. Estrutura Fundamental do Documento HTML

💡 Conceito Fundamental: O HTML (HyperText Markup Language) não processa cálculos nem executa loops (não é linguagem de programação). Trata-se de uma linguagem de marcação: usa "etiquetas" (tags) para delimitar o papel estrutural de cada elemento para o navegador.

🏷️ Anatomia de uma Tag: Abertura, Atributos e Conteúdo

Um elemento HTML com conteúdo funciona como um envelope delimitado por abertura e fechamento:

<a href="https://w3c.org" target="_blank">Acessar W3C</a>
ComponenteExemploFunção Técnica
Tag de Abertura<a ...>Marca o início do elemento na árvore do DOM.
Atributo (Chave)href, target, id, classPropriedade que altera ou parametriza o comportamento.
Valor do Atributo"https://w3c.org"Dado atribuído à propriedade.
ConteúdoAcessar W3CInformação visível ou elemento aninhado.
Tag de Fechamento</a>Finaliza o escopo do elemento.

🌳 A Árvore do Documento: <head> vs <body>

<html>
A raiz. Envolve TODO o documento.
<head>
Invisível ao usuário. Guarda metadados técnicos.
<meta> / <title>
Configuram codificação e título da aba.
<body>
Tudo o que o usuário vê e com o que interage.
<h1> / <p> / <img>
Elementos de conteúdo renderizados na tela.
👆 Clique em um bloco da árvore

head é a ficha técnica; body é o palco visual.

🔍 Elementos Vazios (Void Elements): Diferente dos elementos comuns, que funcionam como envelopes com texto dentro, tags como <img>, <br>, <hr>, <input> e <meta> são elementos vazios: não possuem tag de fechamento (nunca escreva </img>) e inserem o recurso de forma autocontida através de seus atributos.

📐 2. Layout Semântico

O HTML5 introduziu tags semânticas para comunicar a função de cada bloco:

<header>
<nav>
<main>
<section>
<article>
<aside>
<figure> + <figcaption>
<footer>

<header>

Cabeçalho introdutório de uma página ou seção.

<header> <h1>Meu Portal</h1> </header>
⚖️ section vs article: article = autônomo (post, notícia compartilhável); section = temático agrupador (Sobre, Preços, Depoimentos).

🚨 5. Modo Caos

      

        
📄 cafe-do-dev.html — versão com bugs

        
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Café do Dev</title>
</head>
<body>
  <header>
    <h1>Café do Dev </header>
    <p>O melhor café da região.</p>
  </header>

  <section>
    <h2>Nosso cardápio</h2>
    <img src="expresso.jpg">
    <ul>
      <li>Expresso — R$ 8,00</li>
      <li>Capuccino — R$ 12,00</li>
    </ul>
  </section>

  <footer>
    <a href="contato.html" target="_blank">Fale conosco</a>
  </footer>
</body>
</html>

        

          🧩 Três erros plantados.
          
Dica: tag de fechamento, atributo obrigatório e boa prática de segurança.

          
        

        

          
Erro 1: <h1> fechado com </header>.

          
Erro 2: <img> sem alt.

          
Erro 3: target="_blank" sem rel="noopener noreferrer".
